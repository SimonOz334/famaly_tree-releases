# Корни — семейное дерево для Windows

[Скачать установщик FamilyTreeSetup.exe](https://github.com/SimonOz334/famaly_tree-releases/releases/latest/download/FamilyTreeSetup.exe)

Запустите скачанный файл, выберите, нужен ли ярлык на рабочем столе, и нажмите **Установить**. Установщик скачает приложение с GitHub для текущего пользователя и добавит его в меню **Пуск**. Для установки нужен интернет. После установки приложение работает и без подключения.
