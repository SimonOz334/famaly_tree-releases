# Корни — семейное дерево

«Корни» — настольное приложение для Windows. В нём можно составить семейное дерево, связать родственников, сохранить даты, биографии и фотографии. Дерево хранится на компьютере и открывается без интернета.

**[Скачать установщик для Windows](https://github.com/SimonOz334/famaly_tree-releases/releases/latest/download/FamilyTreeSetup.exe)** · [Все релизы](https://github.com/SimonOz334/famaly_tree-releases/releases)

## Требования

| Что нужно | Для чего |
| --- | --- |
| Windows 10 или Windows 11 | Для запуска программы и установщика |
| .NET Framework 4.x | Компонент входит в Windows 10 и Windows 11. Если Windows просит установить или обновить его, см. [инструкцию Microsoft](https://learn.microsoft.com/ru-ru/dotnet/framework/install/on-windows-10) |
| Интернет | Нужен для установки, проверки и скачивания обновлений. Дерево можно открывать и редактировать без сети |
| Свободное место | Установщик и приложение версии 1.2.6 вместе занимают около 270 КБ. Размер самого дерева зависит от количества записей и фотографий |

Для установки подходят права обычного пользователя. Аккаунт GitHub не требуется.

## Установка и запуск

1. Скачайте **FamilyTreeSetup.exe** по ссылке выше и откройте файл.
2. Оставьте галочку **«Создать ярлык на рабочем столе»**, если нужен ярлык, и нажмите **«Установить»**.
3. Нажмите **«Запустить „Корни“»** в установщике. Позже приложение можно открыть через ярлык или меню **Пуск**.

Программа устанавливается в `%LOCALAPPDATA%\Programs\Korni`. Если нужен запуск без установки, скачайте [FamilyTree.exe из релиза](https://github.com/SimonOz334/famaly_tree-releases/releases/latest/download/FamilyTree.exe) и поместите его в папку, куда можно сохранять файлы.

## Если Windows показывает «Система Windows защитила ваш компьютер»

Это предупреждение Microsoft Defender SmartScreen. Он проверяет репутацию загруженного файла и его издателя. Файлы версии **1.2.6** опубликованы без цифровой подписи, поэтому SmartScreen может показать это окно при запуске. [Как работает SmartScreen](https://learn.microsoft.com/ru-ru/windows/apps/package-and-deploy/smartscreen-reputation)

1. Убедитесь, что файл скачан с [официальной страницы релизов «Корни»](https://github.com/SimonOz334/famaly_tree-releases/releases).
2. Проверьте контрольную сумму SHA‑256. Для установщика в папке «Загрузки» откройте PowerShell и выполните команду. Если файл лежит в другом месте, подставьте его путь. [Справка Get-FileHash](https://learn.microsoft.com/ru-ru/powershell/module/microsoft.powershell.utility/get-filehash)

   ```powershell
   Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\FamilyTreeSetup.exe" -Algorithm SHA256
   ```

3. Сравните значение **Hash** с таблицей. Совпадение означает, что файл идентичен опубликованному в релизе.

**Контрольные суммы [релиза v1.2.6](https://github.com/SimonOz334/famaly_tree-releases/releases/tag/v1.2.6)**

| Файл | SHA‑256 |
| --- | --- |
| [FamilyTreeSetup.exe](https://github.com/SimonOz334/famaly_tree-releases/releases/download/v1.2.6/FamilyTreeSetup.exe) | `5a48733610d716dc329d07169b9ccd1788711caf75eee931541336715540718f` |
| [FamilyTree.exe](https://github.com/SimonOz334/famaly_tree-releases/releases/download/v1.2.6/FamilyTree.exe) | `0ae52f70aab064cc7038b4b2611dd41654f8883972619e42aaf4b182bd54e259` |

Если сумма совпала и вы доверяете источнику, в окне SmartScreen нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**, если Windows показывает эту кнопку. [Рекомендации Microsoft для первого запуска](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/publish-first-app#step-6-handle-smartscreen-for-new-apps)

Если сумма отличается или антивирус сообщает об угрозе, выберите **«Не выполнять»**. Если кнопки продолжения нет на рабочем или учебном компьютере, обратитесь к администратору. Отключать SmartScreen для установки не нужно.

## Как пользоваться

- **Добавить родственника.** Нажмите **«Добавить человека»**, укажите ФИО и при желании добавьте фото в формате JPG, PNG или BMP. Для даты можно открыть календарь или начать писать цифры. Шаблон `__.__.____` появится при вводе. Если в поле не останется цифр или в меню даты выбрать **«Не указано»**, поле снова покажет эту надпись.
- **Связать карточки.** Зажмите кружок посередине нижней границы карточки и перетащите на другого человека. Выберите **«Супруги»**, **«Бывшие супруги»** или укажите, кто из двоих родитель. Если нужная карточка за краем, задержите там курсор, чтобы прокрутить схему.
- **Прочитать семейную ветку.** От двух родителей идёт общая линия к детям. Когда хватает места, ребёнок стоит посередине под родителями, а несколько детей располагаются симметричной группой. В плотном дереве карточки раздвигаются, чтобы сохранить промежутки.
- **Удалить связь.** Щёлкните по линии и нажмите **Delete** или откройте меню правой кнопкой. На общей ветке программа покажет имена обеих карточек для каждой связи. Пункт **«Убрать „Мама“ из списка родителей карточки „Сын“»** удалит именно эту связь.
- **Выбрать цвет карточки.** Подписи вроде «Папа» и «Сын» автоматически получают голубой фон, а «Мама» и «Дочка» — розовый. Свой вариант можно выбрать в поле **«Цвет карточки»**.
- **Указать родителей и детей.** В карточке откройте список **«Родители»** или **«Дети»**, отметьте нужных людей галочками, нажмите **«Готово»**, затем сохраните карточку. Например, чтобы связать уже созданные карточки деда и отца, у деда откройте **«Дети»** и отметьте отца. В списке родителей у отца появится дед. В карточке можно указать до двух родителей.
- **Указать супругов.** В списке **«Супруги»** справа есть колонки **«Супруг(а)»** и **«Бывший(ая)»**. Отметьте нужную колонку напротив имени. Галочка в соседней колонке снимется автоматически. Действующие супруги соединяются сплошной линией, бывшие — пунктиром.
- **Найти родственника.** Введите имя или место рождения в поиск и нажмите Enter. На дереве Enter переводит выделение к следующей карточке, а в форме — к следующему полю.
- **Посмотреть ветку.** Выберите человека, затем откройте меню **«Всё дерево»** и выберите **«Предки»** или **«Потомки»**. Поиск и список людей доступны и при просмотре отдельной ветки.
- **Открыть подробности.** Нажмите **«Карточка»** на панели над схемой. Справа появятся данные выбранного человека и список его родственников. Нажмите на имя родственника, чтобы перейти к нему.
- **Перемещать дерево.** Перетаскивайте фон. Колесо меняет масштаб, а **«Уместить»** возвращает общий вид.

Если известна только одна дата, на месте второй стоит **…**. Когда обе даты неизвестны, карточка показывает **«Нет данных»**. Возраст отображается, когда его можно рассчитать.

## Обновления

- Для ручной проверки откройте **Данные → Проверить обновления**. Номер установленной версии виден в том же меню.
- Автопроверка включена по умолчанию. Она выполняется при запуске и каждые 6 часов, пока открыто приложение. Её можно отключить через **Данные → Автопроверка обновлений**.
- Если доступна новая версия, программа предложит её установить. Нажмите **«Да»**, чтобы «Корни» скачали и проверили файл, установили его и снова открылись. Семейное дерево и ярлыки сохраняются.
- Нажмите **«Нет»**, чтобы отложить обновление. Вернуться к нему можно через кнопку с номером новой версии внизу окна или через меню **Данные**.

Самостоятельная установка обновлений работает начиная с **1.1.2**. Чтобы перейти со старой версии, скачайте **FamilyTreeSetup.exe** по ссылке в начале страницы, закройте «Корни» и запустите установщик. Если запускаете программу без установки, закройте её и замените `FamilyTree.exe` в своей папке. Дерево хранится в соседнем `family-data.json`.

## Данные и резервные копии

После первого сохранения появится `family-data.json`. В установленной версии он лежит в `%LOCALAPPDATA%\Programs\Korni`, а при запуске без установки — рядом с `FamilyTree.exe`. В этом файле также хранятся фотографии.

«Корни» 1.2.0 открывают деревья предыдущих версий. После сохранения в 1.2.0 для открытия этого файла понадобится версия 1.2.0 или новее.
Для деревьев, в которых отмечены бывшие пары, нужна версия 1.2.3 или новее.
Связи из поля «Встречается с» версии 1.2.4 открываются в списке «Супруги». Для сохранённых деревьев с несколькими супругами у одного человека нужна версия 1.2.5 или новее.

Чтобы перенести дерево на другой компьютер, откройте **Данные → Сохранить резервную копию**, перенесите JSON и выберите **Данные → Импортировать дерево** на новом компьютере. Семейные данные и резервные копии хранятся локально.

## Частые проблемы

| Проблема | Что сделать |
| --- | --- |
| Установщик не скачивает приложение | Проверьте подключение и доступ к [странице релизов](https://github.com/SimonOz334/famaly_tree-releases/releases). Можно скачать сам `FamilyTree.exe` и запустить из обычной папки |
| На рабочем столе нет ярлыка | Откройте «Корни» из меню **Пуск** или снова запустите установщик с галочкой создания ярлыка |
| После переезда в другую папку дерево пустое | Импортируйте резервную копию или поместите прежний `family-data.json` рядом с программой |
